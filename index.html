Free Vercel Serverless Deployment Guide

To hide API keys securely on the server side instead of browser storage, deploy Sohaib AI for free on Vercel:

  1. Create a free account on Vercel.com and install Node.js locally.
  2. Structure your project folder like this: 
    my-sohaib-ai/
├── index.html
├── vercel.json
└── api/
    └── chat.js
  3. Add Environment Variables in Vercel Settings:
    • GEMINI_API_KEY
    • OPENROUTER_API_KEY
    • OPENAI_API_KEY
  4. Run vercel deploy in your terminal. You get a live HTTPS URL with 0 MAD cost!
