Free Vercel Deployment Guide

To keep API keys on the server instead of the browser, deploy Sohaib AI for free on Vercel:

  1. Create a free account on vercel.com and install Node.js.
  2. Organize your project like this: 
    my-sohaib-ai/
├── index.html
├── vercel.json
└── api/
    └── chat.js
  3. Add these Environment Variables in Vercel settings: GEMINI_API_KEY and OPENROUTER_API_KEY.
  4. Run vercel deploy in your terminal. You get a live HTTPS URL at no cost.
